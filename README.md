# スプラ3オートバランス！ 更新版

元の `team-balancer-app.py` をもとにした、Streamlit用の更新版です。

## 2026-11-03：プレイヤー記録の整理

- 「プレイヤーと試合記録」に手動編集・統合・削除を追加しました。手動編集では名前、初期・最新レート、勝敗数、休憩回数、連勝・連敗数を変更できます。試合数と勝率は自動計算します。
- 統合では勝敗・休憩回数を合算し、初期レートと最新レートは、それぞれどちらの人の値を残すか選べます。連勝・連敗は統合先の値を残します。同じ試合に両名が重複していた場合も合算するので、必要に応じて統合後に手動で数値を調整してください。
- 統合した旧名や削除した人は、呼び出し一覧から外れます。現在の参加者枠も同時に統合・削除します。呼び出しは、現在プレイヤー記録に登録されている人だけが対象です。
- 過去の試合履歴は当時の名前・レートを保持します。記録整理後の復元で、削除した人が復活しないようにしています。
- 直前の整理・編集を1回元に戻せます。次に入力・設定・記録を変更すると、この取り消しは使えなくなります。
- 手動編集や統合で調整した数値を過去の試合の取り消しで上書きしないため、整理・編集以前の試合結果の取り消しは停止します。その後の新しい試合は通常どおり結果を訂正できます。
- 試合結果が未入力の間は整理・編集を停止します。結果登録または中止後に操作できます。
- 既存のブラウザ保存データとJSONバックアップを引き続き読み込めます。
- キャラクター画像をページ下部の右側へ移動しました。

## 追加・修正内容

- 同じ端末・ブラウザ・アプリURLで、入力枠、設定、プレイヤー、試合履歴を自動復元します。サーバー再起動時も、ブラウザ側のデータから復元します。
- 「結果未入力」の試合を保存します。結果登録または明示的な中止まで、次のチーム分けを止めます。
- 試合開始時の参加者・休憩者・レート・設定を固定します。入力枠が後から変わっても、試合の勝敗は当時のプレイヤーに記録します。
- 同じ試合を二重登録しません。勝敗・レート・休憩回数を一度の操作で更新します。
- 直前の結果を取り消し、同じチームの勝利側を再入力できます。勝敗、連勝・連敗、レート、休憩回数を戻してから再計算します。
- 初期レートと最新レートを別々に保持し、どちらの値でも過去のプレイヤーを呼び出せます。
- 敗北時のレート減少を標準ONにしました。設定で従来の「勝った人だけ増加」に切り替えられます。
- 連勝・連敗による補正を追加しました。2連続で1.25倍、3連続で1.5倍、4連続で1.75倍、5連続以降は2倍です。OFFにもできます。
- 名前を先にまとめて入力する配置にし、レートも文字入力に変更しました。`２６３０` のように全角のまま入力できます。
- 名前重複、参加ONの空欄、レートの誤入力を検出します。一括入力のエラーで現在の名簿を消さないようにしました。
- 全データのJSONバックアップ・復元、プレイヤー記録のCSV保存、旧版の登録テキスト取り込みを追加しました。

## 保存と入力について

- 自動保存の対象は、Enterまたはフォーカス移動で確定した入力です。画面最上部の「このブラウザに保存済み」を確認して閉じてください。
- 初期レートは、最初に「入力を登録」「一括入力を反映」またはチーム分けしたときの値です。以後の手動レート変更でも初期値は保持します。
- 名前がある枠で参加OFFにした人を、その試合の休憩者として数えます。過去の登録一覧にいるだけの人は休憩に数えません。
- 結果を登録していない試合や、中止した試合には、勝敗・休憩回数を加算しません。
- 名前を同一人物の識別に使います。同名の人は `あお（A）` のように区別してください。名前を変えると別プレイヤーになります。
- 「参加者の入力枠を空にする」操作で、過去のプレイヤーや試合履歴は消えません。
- 日本語入力のON/OFFはブラウザから強制しません。全角数字への対応と、名前・レートの入力順で切り替えの負担を減らします。
- 保存は端末のブラウザ内です。別端末や別ブラウザとの自動共有はありません。シークレットモード、サイトデータ削除、アプリURL変更では同じ保存データを使えないため、JSONバックアップを利用してください。
- ブラウザが保存を拒否した場合は表示します。保存領域の容量を超えた場合も、保存済みと表示せず、バックアップを案内します。
- 複数タブで別の更新を検知した場合、自動保存を止めて警告します。通常は1つのタブで操作してください。
- ブラウザに保存したデータは、アプリ利用時にはStreamlitサーバーのセッションにも送られて処理されます。他の利用者と共有するサーバーファイルやデータベースは使いません。

## レートの計算

標準設定は基本変動率3%、敗北時減少ON、連勝・連敗補正ONです。

`変動量 = 試合直前のレート × 基本変動率 ÷ 100 × 連勝・連敗の倍率`

勝者は加算、敗者は減算します。小数は四捨五入し、変動率が正なら最低1、レートの下限は0・上限は999999です。変動率0%ならレートを変えず、試合結果だけ記録できます。レート0から勝った場合は1増えます。

勝敗が逆になると連続回数は1から再開します。休憩は連続回数を増減させません。減少OFFでは敗北時のレートは据え置きですが、敗北数・連敗数は記録します。

チーム分けは従来どおり合計レート差を最小にします。同じ最小差の候補が複数あればランダムに選びます。奇数人数では人数差の注意を表示します。
